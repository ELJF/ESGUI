请生成一个 3D 线框模型的 C 语言静态数据，模型主题：【在这里填入你想要的模型，例如：飞机 / 火箭 / 恐龙 / 坦克 / 机器人 / 树木】。

必须严格遵守以下规则：

## 1. 数据格式
使用以下结构定义模型：
```c
typedef struct { int32_t x, y, z; } ESGUI_3DPoint_T;
typedef struct { uint8_t a, b; } ESGUI_3DEdge_T;
typedef struct {
    const ESGUI_3DPoint_T *point_list;
    const ESGUI_3DEdge_T  *edge_list;
    uint8_t num_points;
    uint8_t num_edges;
} ESGUI_3D_T;
```

输出必须包含：
- `xxx_points[]`：顶点数组
- `xxx_edges[]`：边数组（每条边是两个顶点索引）
- `xxx`：最终的 `ESGUI_3D_T` 常量

## 2. 坐标系（右手系）
- **x**：左右（宽），正值朝右
- **y**：前后（深度），正值朝前（朝屏幕外/观察者）
- **z**：上下（高），正值朝上

## 3. 坐标必须是纯整数
- 类型为 `int32_t`，**禁止浮点数**
- 所有坐标值必须是整数，不允许出现小数点
- 如果设计过程中出现分数，必须四舍五入到最近的整数

## 4. 中心必须在原点
- 模型的包围盒中心必须等于 `(0, 0, 0)`
- 即三个轴向的 `min + max` 之和应等于 0（或均值 ≈ 0）
- 设计时先确定相对坐标，最后整体平移使中心归零

## 5. 尺寸基准
- 以 **z 方向高度 20** 为基准（即 `z ∈ [-10, 10]`）
- 其他方向可以按真实比例缩放，但高度优先对齐 20
- 整体尺寸应与立方体（20×20×20）在同一视图下比例协调

## 6. 复杂度要求
- 顶点数 **≥ 25**
- 边数尽量多，模型要有明显的结构层次（如主体、附件、细节）
- 避免过于简单的几何体

## 7. 代码风格
- 顶点按功能分组，每组前加 `/* ===== 组名 ===== */` 注释
- 每个顶点行尾加注释，标注序号和功能（如 `// 0 嘴尖`）
- 边列表也按功能分组注释（如 `/* --- 身体纵线 --- */`）
- 使用 `const` 修饰数组

## 8. 拓扑正确性
- 边列表中的索引必须在 `[0, num_points-1]` 范围内
- 不要出现孤立顶点（每个顶点至少属于一条边）
- 尽量让边构成闭合环或网格，方便线框渲染

## 9. 输出示例结构
参考下面这种格式输出：

```c
const ESGUI_3DPoint_T model_points[] = {
    /* ===== 头部 ===== */
    {  0,  5,  8},  // 0  鼻尖
    { -3,  3,  6},  // 1  左眼
    ...
};

const ESGUI_3DEdge_T model_edges[] = {
    /* --- 头部轮廓 --- */
    {0,1}, {1,2}, ...
};

const ESGUI_3D_T model = {
    .point_list = model_points,
    .edge_list  = model_edges,
    .num_points = 30,
    .num_edges  = 52
};
```
